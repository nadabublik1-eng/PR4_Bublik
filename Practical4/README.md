# Практична робота №4

## Тема
Багатопотокове та багатопроцесне програмування в Python.

## Мета роботи
Ознайомитися з основними принципами паралельного програмування, навчитися створювати потоки та процеси, використовувати механізми синхронізації й порівнювати продуктивність послідовного та паралельного виконання задач.

## Опис завдань

### Завдання 1.1. Багатопотоковість
Реалізовано створення та керування потоками за допомогою модуля threading. Проведено порівняння послідовного та паралельного виконання задач.

### Завдання 1.2. Багатопроцесність
Реалізовано паралельне обчислення простих чисел із використанням multiprocessing.Pool. Проведено вимірювання часу виконання та визначено прискорення.

### Завдання 2.1. Синхронізація потоків
Досліджено проблему стану гонитви під час роботи зі спільними даними. Реалізовано банківський рахунок із використанням threading.Lock.

### Завдання 2.2. Semaphore та Event
Реалізовано пул з'єднань з обмеженням одночасного доступу. Використано Semaphore, Event та Lock для синхронізації клієнтських потоків.

### Завдання 3.1. concurrent.futures
Проведено порівняння продуктивності ThreadPoolExecutor та ProcessPoolExecutor для I/O-bound і CPU-bound задач. Реалізовано обробку виключень.

### Завдання 3.2. Producer-Consumer та дедлоки
Реалізовано патерн «виробник-споживач» із використанням queue.Queue. Продемонстровано виявлення потенційного дедлоку та безпечний порядок захоплення замків.

## Запуск програми

Для виконання завдань необхідно встановити Python 3.

Відкрити термінал і перейти до папки проєкту:

```bash
cd Practical4
```

Запуск окремих завдань:

```bash
python3 task_1.1.py
python3 task_1.2.py
python3 task_2.1.py
python3 task_2.2.py
python3 task_3.1.py
python3 task_3.2.py
```

Кожен файл запускається окремо.
